# Project Modes

## Mode A - System Integration

Use for process and infrastructure studies.

Preferred sequence:

1. Problem and requirements
2. Reference system
3. Proposed configuration
4. System boundary
5. Design basis
6. Mass/energy/material balances
7. Subsystem models
8. Heat/work integration
9. Carbon/lifecycle accounting
10. Economics
11. Sensitivity and uncertainty
12. Alternative configurations
13. Deployment constraints
14. Integrated assessment
15. Manuscript

Typical examples:
- nuclear-assisted SMR + CCS;
- industrial heat integration;
- hydrogen systems;
- process decarbonisation.

## Mode B - Mathematical / Numerical

Use for first-principles derivation and model redevelopment.

Preferred sequence:

1. Physical problem
2. Definitions
3. Conservation law
4. Constitutive relations
5. Governing PDE/ODE/system
6. Initial/boundary/interface conditions
7. Analytical solution/reference
8. Discretisation
9. Implementation
10. Verification
11. Convergence
12. Validation against experiment/literature
13. Manuscript

Typical examples:
- TRISO source-term derivation;
- diffusion;
- transport;
- reactor physics submodels.

## Mode C - Evidence / Review

Use where the main deliverable is evidence synthesis.

Sequence:
question -> search strategy -> source retrieval -> screening -> extraction -> contradiction analysis -> evidence grading -> synthesis -> manuscript/recommendation language

## Mode selection

If a project contains multiple modes, define a primary mode and label the others as supporting tracks.
