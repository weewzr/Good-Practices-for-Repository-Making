# CN4252 Nuclear-Assisted SMR + CCS: Transferable Lessons

## What worked

- Explicit competing hypotheses prevented the nuclear heat concept from becoming an assumed conclusion.
- The system boundary was progressively extended from process balance to lifecycle and deployment constraints.
- Canonical results were separated from historical screening states.
- A master number provenance register, source register and assumption register made numerical claims auditable.
- Progressive manuscript development prevented one-pass rewriting from changing the scientific model invisibly.
- Reproducible Rust code plus deterministic CSV/figure generation tied calculations to the manuscript.
- Independent reviews were closed through targeted corrections rather than broad rewrites.
- Figures were treated as topology/meaning specifications, not decorative illustrations.
- The final interpretation remained a conditional model result rather than a claim of commercial Singapore deployment.

## What should not be repeated

- Repeated broad literature passes without a new evidence question.
- Triggering reviews merely because another research pass occurred.
- Introducing economic or engineering numbers before their provenance and role are fixed.
- Treating remaining reactor thermal capacity as equivalent to electrical output.
- Treating literature design-study quantities as commercial qualification evidence.
- Mixing process feasibility, model closure and deployment feasibility.
- Making the report sound more certain than the underlying boundary and assumptions support.

## Reusable system-integration pattern

reference system
-> proposed system
-> system boundary
-> design basis
-> balances
-> subsystem models
-> integrated results
-> sensitivity
-> alternatives
-> deployment
-> economics
-> conclusion

## Important scientific-writing lesson

Use:
physical question -> mechanism -> technical term -> equation/model -> inputs/provenance -> result -> interpretation -> next use

instead of generic academic filler.
