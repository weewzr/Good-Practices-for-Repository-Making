# Model Validation Matrix

## Purpose

Validation is evidence that a model represents physical reality for an intended use. It is not synonymous with code verification or benchmark agreement.

## Condition matching checklist

For each comparison consider:
- geometry;
- composition/material;
- temperature/pressure/state;
- initial condition;
- boundary conditions;
- forcing/source;
- measurement definition/location;
- time/averaging basis;
- scale;
- experimental uncertainty.

## Interpretation

If important conditions are unmatched, classify the evidence as benchmark/comparison evidence rather than quantitative physical validation.

## Extrapolation

Record explicitly when the intended prediction domain lies outside the validation domain.
