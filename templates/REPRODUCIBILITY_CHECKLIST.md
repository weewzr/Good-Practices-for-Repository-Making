# Reproducibility Checklist

## Inputs
- [ ] Inputs listed
- [ ] Sources/versions recorded
- [ ] Units/schema documented

## Environment
- [ ] Runtime/compiler recorded
- [ ] Dependencies recorded/locked where practical
- [ ] External tools recorded

## Execution
- [ ] Core reproduction command documented
- [ ] Verification/test command documented
- [ ] Random seed policy documented if applicable

## Outputs
- [ ] Canonical outputs identified
- [ ] Generated outputs separated from manually authored files
- [ ] Figures/tables traceable to scripts/data

## Clean reproduction
- [ ] Workflow tested without relying on undocumented local state
- [ ] Known platform limitations documented
